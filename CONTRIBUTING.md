# Как добавить свой релей

1. Поднимите релей `qulogid` на хосте с доступом в открытый интернет:

   ```bash
   qulogid -listen :443 -psk <секрет>
   ```

   Для транспорта `storage-webdav` хост с публичным IP не нужен — достаточно аккаунта на белом облаке (Яндекс Диск и любой совместимый WebDAV):

   ```bash
   qulogid -listen "" -dav https://webdav.yandex.ru -dav-user <логин> -dav-pass <пароль> -dav-mailbox qulogi -psk <секрет>
   ```

2. Пришлите pull request, добавляющий релей в `relays.json`:

   ```json
   {
     "id": "ваш-уникальный-id",
     "region": "ru-central",
     "weight": 50,
     "comment": "домашний VPS, 100 Мбит/с",
     "transports": [
       { "type": "qulogi-tls", "addr": "r1.example.net:443", "sni": "vkvideo.ru" }
     ]
   }
   ```

3. Сопровождающие проверяют релей (живость, формат, замечания) и подписывают новый `catalog.json` пиновым ключом. PR без подписи в `main` не попадёт — CI проверяет.

Правила:

- один PR — один релей;
- `addr` — домен или IP с портом; для `qulogi-tls` желателен `sni` из белых платформ;
- не публикуйте `psk` в PR — он раздаётся вашим пользователям ссылками `qulogi://`;
- релей, который недоступен неделю, будет снят с публикации.
